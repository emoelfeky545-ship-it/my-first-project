NOVA'S POWER QUEST

How to run:
1) Open index.html in any modern browser, or upload the whole folder to any static hosting service.
2) Keep the assets folder next to index.html.

What's new in this version
- Only ONE Nova on the map (the painted robot was removed from map-bg-hq.webp and stage1-hover.webp).
- Nova walks along the dotted trail between stages with little hops (no more straight line).
- New music: piano, soft bells, pads and a real reverb; songs have A / B sections and a build-up; map <-> quiz cross-fade.
- Success music starts together with the result pop-up: fanfare, wind/brass theme, build-up, key change, cymbal + applause.
- The map fills the screen on wide screens and on portrait phones (swipe sideways; it follows Nova).
- Quiz screen fits the screen with no scrolling (hint and feedback share one slot; Next button is always at the bottom).
- Final screen: stars / energy / correct summary + certificate with the player's name (saved as a PNG) + Play Again.
- Player name + 5 Nova colours (tap the palette button in the top bar any time). The colour also changes the game theme.
- Stars now count the BEST result of each mission (max 9).
- In-game confirm box instead of the browser confirm().
- After a failed mission the button says "Try Again" (plus a "Back to Map" button).
- Music and sounds pause when the tab is hidden or the browser is minimised.

- Nothing is saved between visits: every time the game opens it starts from the beginning (name, Nova colour, stars, stages, sound).

Unchanged on purpose: the 9 questions (no new questions were added), the energy rules.

Original files (before this update) are in the "originals" folder: index.html, map-bg-hq.webp, stage1-hover.webp.
